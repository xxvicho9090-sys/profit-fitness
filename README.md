# ProFit

PWA de entrenamiento: 870+ ejercicios (hombre y mujer), rutinas generadas por sexo/objetivo, registro de series con 1RM estimado y récords, +45 mediciones corporales con gráficas y 13 calculadoras (1RM, % grasa, TMB/macros, zonas de FC, VO2máx, Wilks, discos…).

- Sin build: HTML/CSS/JS estático. Datos en `localStorage` (exportables).
- Base de ejercicios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (dominio público).
- Local: `npx http-server . -p 5174`
- Deploy: Render Static Site (ver `render.yaml`), publish dir `.`
